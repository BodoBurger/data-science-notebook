## Overview

[uv](https://docs.astral.sh/uv/) is a modern Python package and project manager, replacing `pip`, `poetry`, `pyenv` and `virtualenv` among others.

For a replacement of `conda` go for [Pixi](https://pixi.prefix.dev/).

## Installation

Follow the instructions on: https://docs.astral.sh/uv/getting-started/installation/
